# Filament Recommendations Plugin

Filament v5 plugin that adds a recommendation engine to your Laravel application. Supports co-occurrence ("who also viewed"), content-based similarity, and collaborative filtering strategies — with first-class single-tenant and multi-tenant support.

## Requirements

- PHP 8.3+
- Laravel 12+ / 13+
- Filament 5.x

The full documentation is also accessible from the Filament panel at **Recommendations → Documentation**.
